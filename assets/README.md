# Marglow brand assets

The identity pairs a reading page with a spark of insight, reflecting **margin + glow**.

- `marglow-banner.png`: full-color README banner, 2172 × 724 px. Both language editions use this file.
- `marglow-icon.svg`: editable monochrome line mark. Its 100 × 100 viewBox and `currentColor` strokes work with Obsidian's native icon registry, including light/dark themes. It is bundled into the plugin; no network or external asset loading is required.

The icon was drawn directly as SVG. The banner was generated using the built-in image generation tool with the following final prompt:

> Use case: logo-brand. Asset: final polished wide GitHub README banner for Marglow, an Obsidian reading annotation plugin. Landscape 3:1 composition. Exact and ONLY text: "Marglow", elegantly typeset large, perfectly legible, contemporary rounded sans serif, off-white. Brand motif: a simple upright rounded page outline, two short text strokes and a highlighted underline inside, one small four-point sparkle at its upper-right margin. Place this distinctive emblem beside the wordmark as one balanced central lockup with generous breathing room. Make emblem crisp and simple, in luminous lilac and warm golden yellow. Backdrop: deep midnight violet, with sophisticated soft flowing aurora ribbons of purple, mint teal, blush pink and amber around the outside; subdued fine grain and subtle glow, rich color but spacious editorial restraint. Avoid clutter, extra words, slogan, watermark, app screenshots, pen illustration, 3D mockups, tiny ornamental stars, excessive lens flares. It should feel like quiet reading with a bright moment of insight. Full bleed rectangular banner; no outer frame.
